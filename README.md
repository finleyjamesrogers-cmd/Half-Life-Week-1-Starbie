# Starbie Adaptation
Starbie is a tiny motion-controlled digital pet with minimal gameplay buttons. Instead of pressing buttons, you interact with it by physically moving the board.

<img width="660" height="621" alt="Screenshot 2026-10-10 143050" src="https://github.com/user-attachments/assets/c5110295-6a3d-4e61-a3e7-a3eabcead6ec" />

## What is it?
The Starbie is designed to be your own personal digital pet that can show its personality through a small display, react to the way you handle it and give real time responses and feedback.

The board includes a microcontroller, display, gyro/motion sensor and Temperature/Humidity Sensor all in a compact PCB design.

It is powered by USB and made for beginner-friendly through-hole soldering for the add on components

## Why?
This project was created to complete week 1 of half life 2026

## Highlights
- Temperature and Humidity sensors to get real time info
- Gyro based selector to make it more interactive without the need to add more buttons
- Customisable beginner section of Arduino code for easy ways to make it harder/easier to keep your pet happy
- Small display for real time feedback and visual selection/prompts

## Visual Features
- Tilt control selection.
- Sparkles that follow the pet.
- Visual indicators of sleep/love in the form of Zz's and Hearts.
- Pet explores around when not being instrusted.
- Little shake to acknowledge instruction.
- Lots more, look through the code or build it to find out!  

## Project Status
The PCB design as well as the Arduino starter firmware are included, the default program is a turtle pet with a tilt-controlled radial menu, hidden stats, and a range of reactions going from dancing to eating to sleeping.

## What was used to make it?
The original tutorial Starbie, by SharKingStudios was used to guide most of the design with extra input from myself for the creative design features including the pet sprite.

- KiCad was used for the PCB schematics, design and routing.

- Arduino was used for the firmware.

- Piskel was used for creating the turtle sprite.
